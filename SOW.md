ТЗ: Разработка сервиса извлечения персонажей из видео и генерации их ростовых фото

Цель: Разработать сервис на Python, который принимает на вход короткое видео с несколькими героями, автоматически находит всех уникальных ключевых персонажей и генерирует для каждого из них качественное фото в полный рост с сохранением внешности.

Входные данные:
- Короткий видеоролик (5–10 секунд, MP4, 2–3 персонажа в кадре, которые могут перемещаться или перекрывать друг друга).

Выходные данные:
- Изображениями персонажей (по 1 ростовому фото на каждого уникального найденного героя).

Функциональные требования:

1. Анализ видео и трекинг персонажей:
   * Автоматическая детекция всех людей в кадре по ходу ролика.
   * Отбор и дедупликация уникальных персонажей (различение разных людей и исключение дублей одного человека).
   * Выбор наилучших референсных кадров(с наименьшим размытием и хорошей видимостью лица/одежды).

2. Генерация фото персонажей:
   * На основе собранных референсов сервис генерирует по одному ростовому фото на каждого уникального персонажа.
   * Сохранение внешности: Черты лица, прическа, цвет кожи, одежда и стиль должны максимально совпадать с оригиналом из видео.
   * Формат фото: Персонаж стоит в полный рост на нейтральном фоне, ракурс анфас или 3/4.

3. Инструменты и стек:
   * Язык программирования: Python 3.10+
   * Разрешено использовать любые внешние API (Replicate, fal.ai, OpenRouter, Runway и др.) и открытые библиотеки (YOLO, OpenCV, MediaPipe, ComfyUI, PyTorch).
