# Video Character Extractor

Локальный сервис принимает короткое MP4-видео с 2–3 героями, находит уникальных
персонажей и генерирует по одному полному PNG для каждого. Поддерживаются реальные
люди, 2D/3D-персонажи, животные, роботы и фантастические существа.

## Быстрый запуск на Windows

### 1. Подготовьте Python

Нужен 64-битный Python 3.10, 3.11 или 3.12. Рекомендуется Python 3.11.

Проверить установленные версии:

```powershell
py -0p
```

Если Python 3.11 отсутствует:

```powershell
winget install -e --id Python.Python.3.11
```

После установки закройте и заново откройте PowerShell:

```powershell
py -3.11 --version
```

### 2. Скачайте проект

На странице репозитория нажмите **Code → Download ZIP**, распакуйте архив и
откройте PowerShell в полученной папке. Либо используйте Git:

```powershell
git clone https://github.com/MaimeD666/spacestest.git
cd spacestest
```

### 3. Установите зависимости и модели

```powershell
py -3.11 install.py
```

Установщик создаст локальное окружение `.venv`, установит зависимости и загрузит
проверенные веса YOLOE/MobileCLIP. Это выполняется один раз и может занять
несколько минут.

### 4. Добавьте ключ Google

```powershell
notepad .env
```

Заполните строку:

```dotenv
GOOGLE_API_KEY=ваш_ключ
```

Ключ Google AI Studio необходим для дедупликации и генерации изображений.

### 5. Проверьте и запустите

```powershell
.venv\Scripts\python.exe run.py --check
.venv\Scripts\python.exe run.py
```

Откройте <http://127.0.0.1:8000> и загрузите MP4. Остановка сервера — `Ctrl+C`.

Также можно выполнить `.\start.ps1`. Если PowerShell запрещает запуск
сценариев, используйте прямую команду с `.venv\Scripts\python.exe`, показанную
выше: она не требует изменения политики PowerShell.

## Запуск на macOS и Linux

Нужен Python 3.10–3.12:

```bash
git clone https://github.com/MaimeD666/spacestest.git
cd spacestest
python3 install.py
```

Добавьте `GOOGLE_API_KEY` в созданный `.env`, затем:

```bash
.venv/bin/python run.py --check
sh start.sh
```

Панель откроется на <http://127.0.0.1:8000>, OpenAPI — на
<http://127.0.0.1:8000/docs>.

## Как работает обработка

```text
MP4
  → OpenCV: выбор кадров
  → YOLOE: детекция персонажей
  → TrackTrack + ReID: трекинг
  → рейтинг и отбор лучших кропов
  → Gemini Flash-Lite: дедупликация
  → Gemini Flash Image: полный PNG
```

Кадры оцениваются по резкости, размеру персонажа, обрезке границами кадра,
уверенности детектора и экспозиции. Для каждого трека сохраняются лучшие
разнесённые по времени изображения.

После перекрытия один персонаж может получить несколько tracker ID. Gemini
получает только выбранные кропы и их `reference_id`, `track_id`, класс детектора
и оценку качества. Модель группирует одинаковых героев и возвращает structured
JSON по Pydantic-схеме. Сервер проверяет все ID и отбрасывает неизвестные значения.

Для генерации передаются до четырёх референсов, описание внешности, анатомии и
исходного визуального стиля. 2D остаётся 2D, 3D сохраняет материалы и пропорции, а
негуманоидным героям не добавляется человеческая анатомия.

## API

Создать задание:

```bash
curl -X POST http://127.0.0.1:8000/v1/jobs \
  -F "video=@/path/to/clip.mp4"
```

Получить состояние:

```bash
curl http://127.0.0.1:8000/v1/jobs/JOB_ID
```

Статусы: `queued`, `analyzing`, `deduplicating`, `generating`,
`completed`, `failed`. После завершения ссылки на PNG находятся в
`characters[].image_url`.

Удалить завершённое задание и его файлы:

```bash
curl -X DELETE http://127.0.0.1:8000/v1/jobs/JOB_ID
```

## Основные настройки

Параметры задаются в `.env`:

| Переменная | По умолчанию | Назначение |
|---|---:|---|
| `DETECTION_MODE` | `universal` | Любые персонажи или только `people` |
| `DEVICE` | `auto` | CUDA → MPS → CPU |
| `ANALYSIS_FPS` | `8` | Частота анализа кадров |
| `MAX_VIDEO_SECONDS` | `15` | Максимальная длительность MP4 |
| `MAX_UPLOAD_MB` | `100` | Максимальный размер файла |
| `MAX_CHARACTERS` | `3` | Максимум итоговых персонажей |
| `IMAGE_SIZE` | `2K` | Запрашиваемый размер изображения |
| `JOB_RETENTION_HOURS` | `168` | Срок хранения завершённых заданий |

При `DEVICE=auto` сервис использует CUDA, затем Apple MPS, затем CPU. GPU не
обязателен, но обработка YOLOE на CPU будет медленнее.

## Приватность, стоимость и ограничения

- MP4, кропы и результаты хранятся локально в `data/jobs`.
- В Google API отправляются выбранные кропы и текстовый контекст; исходный MP4
  целиком не отправляется.
- Один job использует один запрос дедупликации и по одному запросу генерации на
  каждого найденного персонажа. Стоимость зависит от текущего тарифа Gemini.
- Детали, которых нет ни на одном референсе, невозможно восстановить точно.
- Размытые, маленькие или полностью перекрытые персонажи могут быть пропущены.
- Результат генерации необходимо визуально проверять.
- Для закрытого коммерческого использования следует проверить условия лицензии
  Ultralytics AGPL-3.0/Enterprise.
